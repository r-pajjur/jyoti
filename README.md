# Jyoti 🪔

A 30-day post-yatra ritual PWA. One gentle prompt each morning; posting a photo
or a reflection unlocks that day's shared feed. Built for ~25 non-technical
users on iPhone Safari.

## Stack

- **Frontend** — plain TypeScript bundled by esbuild into `public/app.js`. No framework.
- **Backend** — Vercel serverless functions in `api/`.
- **Board** — Padlet (JSON:API). Posts, reactions, and comments all live there.
- **Photos** — Vercel Blob. Padlet's API accepts an attachment **URL** only, never a file.
- **Look** — sandalwood and saffron, matching lifeseva.ca (Fraunces + Inter).

There is no push, no cron, and no subscriber database: the daily nudge goes out
by hand over WhatsApp. The app simply shows whichever day it is, counting
forward from `JYOTI_START_DATE`.

## One screen, then the river

**Today** opens closed. You see how many of the group have gone before you —
"3/20 lamps lit" — and nothing else. Not the prompt, not the posts. The prompt
is withheld by the server, not merely hidden by the UI, and appears when you
tap *Add your drop to the river*.

Posting opens the day's feed, where each drop can be blessed with a heart. No
counts on the hearts: you can tell someone you saw them without it becoming a
score.

**The river** — the month as a compact grid of days, reachable only once you
have added today's drop. Tap any past day to see what the group gathered. It is
the group's thread, not yours; there is no private view.

Set the group size with `JYOTI_GROUP_SIZE` (default 20).

## Try it with no credentials

```bash
npm install
npm run demo          # → http://localhost:4000
```

Runs the real handlers against an in-memory Padlet and Blob. Starts on Day 3,
with two past days seeded and two people already posted today, so the reveal
gate is visible immediately.

## Setup for real

```bash
cp .env.example .env          # fill PADLET_API_KEY, PADLET_BOARD_ID, JYOTI_START_DATE
vercel env pull .env          # pulls BLOB_READ_WRITE_TOKEN once Blob is connected
npm run test:padlet           # verify the photo→Padlet path against a scratch board
npm test                      # 19 offline checks of the handlers
npm run build
```

## Layout

```
api/            serverless functions; _lib/ is shared and never routed
src/            frontend TypeScript; screens/ is one file per screen
scripts/        icon generation, the demo server, and the two test harnesses
public/         static shell — app.js and sw.js are generated by build.mjs
```

## Regenerating artwork

`npm run icons` re-renders every icon and the in-app lamp from
`scripts/lib/lamp.mjs`. There are no binary design assets in the repo.
